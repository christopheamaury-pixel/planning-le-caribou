# Planning Airbnb — prototype iPhone/iPad

Cette version est une application web progressive (PWA) indépendante d'Excel.
Elle contient :
- calendrier mensuel tactile ;
- réservation issue du planning fourni (Loic Chobriat, 7 nuits, 945,21 €) ;
- ajout / modification / suppression ;
- rappel des vacances scolaires A/B/C ;
- import/export Excel.

## Installation sur iPhone/iPad
1. Héberger ce dossier sur une adresse HTTPS.
2. Ouvrir l'adresse dans Safari.
3. Partager → Ajouter à l’écran d’accueil.
4. L'icône ouvre l'application en mode indépendant.

## Important
Cette version est un prototype fonctionnel. Le bouton Importer Excel accepte un tableau Excel structuré avec des colonnes Nom, Arrivée, Départ, etc. Ton planning actuel est un calendrier visuel personnalisé : pour une synchronisation bidirectionnelle automatique avec le fichier Excel stocké dans iCloud Drive, il faut une étape supplémentaire de connexion à la structure exacte du classeur.
